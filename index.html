スプレッドシートのリンクを設定

スプレッドシートを「ファイル → 共有 → ウェブに公開」でCSV公開し、そのリンクを貼り付けてください。空のままだとサンプルデータで表示します。

このボードの使い方

物件を買い取って売るまでの進み具合と、いくら儲かるかを、一目で見るための画面です。データの入力はスプレッドシートで行い、この画面はそれを見やすく表示します（この画面から直接の書き換えはできません）。

物件を1件追加するとき

  1. PDFを読み取る：上の「PDF取り込み」ボタンを押して取り込みツールを開き、ハトサポの契約台帳PDFを枠にドラッグ＆ドロップします。種別・物件名・住所・取得価格・買取契約日・残金決済日が自動で読み取られます。内容を確認し、必要なら直して「スプレッドシートにコピー」を押します。
  2. スプレッドシートに貼る：「スプレッドシートを開く」ボタンでシートを開き、空いている行のいちばん左（A列）をクリックして貼り付け（Ctrl+V）します。これで1件追加されます。
  3. 残りを記入する：PDFにない項目（担当・リノベ予算・リノベ実績・諸経費・売出価格・成約価格）を手で入力します。フェーズ（進み具合）は、その列のセルをクリックすると出るプルダウンから選びます。

物件が進んだとき

スプレッドシートでその物件のフェーズをプルダウンで選び直し、「フェーズ更新日」を今日の日付に書き換えます。売れたら成約価格を入れて、フェーズを「売却完了」にします。

この画面の見方

  • 上の数字：進行中の件数、いま抱えている在庫金額、売却完了した物件の累計利益、平均利益率、要注意の件数。
  • 7つの列：左から 仕入検討 → 買取契約 → 移転完了 → リノベ中 → 販売中 → 契約済 → 売却完了。物件はフェーズの列に並びます。
  • カードの色帯：物件の種別を表します（土地=緑、戸建て=オレンジ、マンション=青、その他=赤）。
  • 赤いバッジ：「予算超過」はリノベ費が予算を超えたとき。「○日停滞」は販売中・契約済のまま長く動いていないとき。会議で注意すべき物件がひと目で分かります。
  • 日程の管理：仕入決済日（残金決済日）を0日目として、売却完了まで180日以内を目標に進み具合を管理します。カードに「○日目」「期限まで○日」が出ます。70日を過ぎても売れていない物件は「価格改定検討」、180日を過ぎると「期限○日超過」が赤バッジで出ます。上の集計にも「価格改定検討」「期限30日以内」の件数が出るので、会議でまずここを確認します。
  • 価格の改定：スプレッドシートに「当初販売価格・1回目改定価格・2回目改定価格」を入れると、いちばん新しく入っている改定価格が自動的に現在の売出価格になり、粗利も連動して計算し直されます。物件カードをクリックすると、価格の変遷と日程アラートが詳細画面に表示されます。
  • ガントチャート：上の「ガントチャート」タブで、物件ごとの工期を時間軸で見られます。点線が各工程の予定日（決済+30日リノベ完了／+37日販売開始／+70・100日価格改定／+130日再販契約／+180日売却完了）、赤い線が180日の期限です。実績の棒が予定の点線より右にあれば遅れ気味、と分かります。
  • カードをクリック：取得価格・リノベ費・粗利・買取契約日・残金決済日などの明細が開きます。

注意

この画面のリンクには取得価格や利益などの社内情報が含まれます。社外の人には共有しないでください。
